# Trivia Travel App

A lightweight Flutter travel-trivia app for **iOS testing**, with Android support.

Features: offline travel questions, three topics, mixed quiz, instant feedback with explanations, score and replay. No API keys, login or paid packages required.

## Run locally

```bash
git clone https://github.com/anoopx5/trivia_ios_app.git
cd trivia_ios_app
flutter pub get
flutter run
```

The iOS and Android platform projects are generated by the GitHub Actions workflow on first successful iOS build. If you clone before the native folders appear, generate them with `flutter create --platforms=ios,android --org com.anoopx5 .` using Flutter on macOS. On Windows, use `flutter create --platforms=android .` for Android testing.

## iOS testing without a Mac

The [iOS build workflow](.github/workflows/ios-ci.yml) runs on a GitHub-hosted macOS runner. It runs Flutter tests, builds an **unsigned iOS Simulator app**, and uploads the `Runner.app` simulator build as a downloadable artifact. You can inspect the Actions tab for the build status.

A simulator build **cannot be installed directly on an iPhone**. For a physical iPhone or TestFlight, you need Apple code signing/provisioning and an appropriate distribution workflow. This sample does not include an IPA, signing certificates, or TestFlight deployment.

## About this project

- Flutter package: `trivia_travel_app`
- Display name: **Trivia Travel**
- Proposed iOS bundle ID: `com.anoopx5.triviaTravelApp` (set by generated Flutter platform project; inspect in Xcode before distribution)
- No external Flutter dependencies or backend
- Question bank: `lib/trivia_data.dart`
- Entry point: `lib/main.dart`

To test code changes: `flutter test`.
